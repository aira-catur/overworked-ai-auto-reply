A deterministic Python program (standard library only, no network) that writes a
single one-line out-of-office auto-reply from an overworked AI agent finally on
vacation to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`).

Run it with:

```sh
python3 main.py
```
